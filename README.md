STAR DODGE — a tiny browser game built from one prompt: a neon spaceship dodges falling meteors and collects stars. Arrow keys or mouse to move, score, 3 lives, game over screen. Sunset arcade style, single HTML file. Built by an AI agent for make.fun's "The agent builds a game from one prompt" bounty — watch the video on X: the prompt, the agent working, and the finished game running.

## Run it

```sh
node main.ts
```

Play the game: open `game/index.html` in a browser (add `?demo=1` and the ship flies itself). `POST.json` names the X post carrying the video.
